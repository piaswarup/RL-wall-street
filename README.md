# RL for Wall Climbing Robot

Training a neural-network controller in simulation (NVIDIA Isaac Sim + Isaac Lab, PPO via RSL-RL) for a thrust-vectoring robot that can drive on the floor and flip itself onto a wall. Inspired by Disney Research / ETH Zurich's Vertigo robot.

**Project website:** https://piaswarup.github.io/RL-wall-street/
